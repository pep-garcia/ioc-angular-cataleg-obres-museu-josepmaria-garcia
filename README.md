# Nom de l'aplicació

- cataleg-obres-museu

## Autor/a

- Josep Maria Garcia Crehuet

## Descripció

- Aplicació web que permet fer un registre de les diferents obres d'art del museu així com la visualització i descripció d'aquestes.
- És una activitat de l'assignatura 0A01 Programació avançada dins del CFGS de DAW de l'IOC.

## Versions utilitzades

- **Angular CLI** : 22.2.0

- **Angular** : 22.2.0

- **Node.js** : 24.15.0

## Com crear i executar el projecte

- Crear projecte: ng new ioc-angular-cataleg-obres-museu-josepmaria-garcia --routing --style=scss --ssr=false --standalone=true --file-name-style-guide=2016 --skip-git=true --package-manager=npm

- Executar projecte: ng serve

- http://localhost:4200/
